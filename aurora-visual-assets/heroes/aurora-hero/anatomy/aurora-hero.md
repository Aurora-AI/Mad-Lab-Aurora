# Anatomy: AuroraHero (aurora-hero-001)

## Visual Identity
- **Concept**: Kinetic puzzle assembly representing operational coherence emerging from chaos.
- **Aesthetic**: `Dark Editorial` / `Paper Editorial`.
- **Palette**:
  - `PAPER`: #F3EDE3 (Ivory background)
  - `INK`: #0D0A07 (Primary text)
  - `RED`: #B91C1C (Accent/Highlight)
- **Typography**:
  - Display: Serif Italic (italicized emphasis on "nós").
  - Body: Modern Sans-serif with high line-height.
  - Mono: Technical metadata and status indicators.

## Technical Orchestration
- **Framework**: React + GSAP.
- **Motion Engine**: ScrollTrigger (Scrub-driven).
- **Smooth Scroll**: Integrated with Lenis.
- **Visual Sequence**:
  - Frame 0: Total chaos (multiply blend).
  - Frame 1: Initial grouping.
  - Frame 2: Energy burst / Head emerging.
  - Frame 3: Final assembly (normal blend, dark transition).

## Governance Tokens
- `governance_type`: High-Fidelity Manual.
- `audit_standard`: CEO-Effects (Motion curve linearity).
- `design_system`: Aurora Core.
