# Aurora Factory — Estado da Fábrica

## Contexto Técnico
A Aurora opera como uma fábrica de software e IA de alta precissão.

## Stack Canônico
- **Frontend**: Next.js, React, TailwindCSS, Framer Motion.
- **3D/Effects**: Three.js (r128), R3F, GSAP, GLSL.
- **Backend**: Node.js, Python (FastAPI).
- **Core IA**: Pipeline de ingestão cognitiva (GEM-Effects, Lex Toolbelt).

## Produtos Ativos
- **Elysian**: Auditoria forense e liquidação de passivos.
- **Lex OS**: Dashboard operacional jurídico.
- **Aurora-Web**: Presença institucional dark editorial.

## Padrão de Qualidade
- **Dark Editorial**: Peso, silêncio, tipografia monospaçada, alta densidade de dados.
- **Performance First**: 60fps em Intel Iris Xe.
