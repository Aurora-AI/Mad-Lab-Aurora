## PARTE I — FUNDAÇÃO FILOSÓFICA

### 1.1 O Que É a Elysian

Elysian é uma fábrica de produtos digitais AI-native que dá superpoderes a pessoas e profissionais.

Não substituímos humanos por IA.
Usamos IA para tornar humanos extraordinários.

A Elysian opera três verticais:

| Vertical | Produto | Promessa |
|---|---|---|
| Comercial | CRM Aurora + Silent Operator | Inteligência comercial que age |
| Jurídico | Elysian Lex | Precisão jurídica sem fricção |
| Criativo | Mad Lab Aurora | Experiências digitais impossíveis |

**A marca Elysian é a empresa. As verticais são os produtos.**
Nenhum produto domina a identidade da marca mãe.

### 1.2 A Origem do Nome

**Elysian** vem dos Campos Elísios — na mitologia grega, o destino dos heróis.
Não o paraíso dos mortos. O lugar onde os que viveram com propósito chegavam.

Essa referência não aparece como ornamento.
Ela aparece como **subtexto** — sentida, não explicada.

A Elysian não é o paraíso. É o caminho para o extraordinário.
Quem usa nossos produtos não se aposenta — se transforma.

### 1.3 A Missão em Uma Frase

> **Dar superpoderes a pessoas usando IA como infraestrutura invisível.**

O que isso significa na prática:
- A IA nunca é o produto. O humano elevado é o produto.
- A tecnologia é invisível. A transformação é visível.
- Confiança e empatia não são valores de parede — são requisitos de design.

### 1.4 O Princípio Da Vinci

A Elysian opera sob o princípio renascentista de beleza como verdade:

> *A beleza não é ornamento. É proporção. É o que acontece quando forma e função se tornam a mesma coisa.*

Isso significa:
- Nada é decorativo por acidente.
- Cada elemento tem razão de existir ou é removido.
- A beleza do produto é evidência da seriedade de quem o construiu.

## PARTE II — PERSONALIDADE E VOZ

### 2.1 Arquétipos da Marca

A Elysian opera em dois arquétipos simultâneos — não escolhe entre eles:

**O Sábio** — conhecimento profundo, sem arrogância.
Sabe mais do que fala. Quando fala, é preciso.

**O Herói** — age no mundo, transforma situações.
Não contempla. Constrói. Entrega. Eleva.

A tensão entre os dois é o que torna a marca interessante.
Um Sábio sem ação é acadêmico. Um Herói sem sabedoria é bruto.
A Elysian é os dois.

### 2.2 Tom de Voz

**O que a Elysian soa:**
- Direta sem ser fria
- Confiante sem ser arrogante
- Técnica sem ser hermética
- Provocadora sem ser agressiva

**O que a Elysian nunca soa:**
- Entusiasmada demais (startup hype)
- Corporativa e distante
- Condescendente com o cliente
- Apologética sobre tecnologia

### 2.3 Princípios de Escrita

**Frase curta antes da frase longa.**
Se uma ideia precisa de 40 palavras, ela começa com 6.

**Concreto antes de abstrato.**
"Reduz em 70% o tempo de resposta comercial" antes de "aumenta eficiência".

**O cliente é o herói. Sempre.**
A Elysian é o mentor. Nunca o protagonista.

**Dark Editorial na escrita:**
Quando o texto precisa criar tensão — quando estamos mostrando a dor que o cliente nem sabe que tem — a escrita vai para o silêncio. Frases fragmentadas. Pausa. Peso.

## PARTE III — SISTEMA TIPOGRÁFICO

### 3.1 Filosofia Tipográfica

A tipografia Elysian opera em **dois registros com igual autoridade**:

O Grotesco Humanista para quando a marca precisa ser próxima, confiante, acolhedora.
O espaço negativo e o silêncio para quando a marca precisa respirar e deixar o conteúdo falar.

Nunca escolhemos entre os dois. Usamos os dois — com intenção.

### 3.2 Fonte Principal — Display e Interface

**Família:** Söhne (Klim Type Foundry) — preferencial
**Alternativa de produção:** GT America (Grilli Type)
**Fallback web:** `system-ui, -apple-system, 'Helvetica Neue', sans-serif`

**Por que Söhne:**
Söhne foi desenhada como uma interpretação contemporânea do grotesco alemão — especificamente da Akzidenz-Grotesk que dominou o design europeu do século XX. Ela carrega autoridade histórica com calor humanista. Não é neutra como Helvetica. Não é fria como Futura. É exatamente a tensão que a Elysian precisa: força que acolhe.

**Pesos em uso:**

| Peso | Uso | Contexto |
|---|---|---|
| Söhne Buch (Book 300) | Corpo de texto longo | Parágrafos, descrições |
| Söhne Leicht (Light 200) | Subtítulos de suporte | Seções luminosas, ar |
| Söhne Kräftig (Medium 500) | UI, labels, navegação | Interface, botões |
| Söhne Halbfett (SemiBold 600) | Headlines secundários | Seções de valor |
| Söhne Dreiviertelfett (Bold 700) | Headline principal | Hero, declarações |
| Söhne Extrafett (ExtraBold 800) | Display máximo | Momentos de impacto |

**O que não usar:**
- Söhne Italic em display — reservado para ênfase em corpo de texto
- Peso acima de 800 — a marca não grita
- Tracking positivo excessivo em pesos pesados — destrói o grotesco

### 3.3 Escala Tipográfica

```
Display XL:   80–120px / weight 700–800 / tracking -3px a -4px
Display L:    56–72px  / weight 700     / tracking -2px a -3px
Headline:     36–48px  / weight 600     / tracking -1px a -2px
Subheadline:  24–30px  / weight 500     / tracking -0.5px
Body L:       18–20px  / weight 300     / tracking 0    / line-height 1.7
Body:         15–16px  / weight 300     / tracking 0    / line-height 1.65
Small:        12–13px  / weight 500     / tracking 0.08em (capslock labels)
Micro:        10–11px  / weight 500     / tracking 0.12em (metadata, tags)
```

**Regra de ouro:**
Quando a tipografia sobe em tamanho, o tracking vai para negativo.
Quando o tamanho cai, o tracking pode ir para positivo (capslock labels).
Nunca tracking positivo em display. Nunca.

### 3.4 Hierarquia na Prática

**Seção luminosa (80% do site):**
- Display: Söhne Bold/ExtraBold, preto sobre off-white
- Corpo: Söhne Book 300, cinza escuro (#1A1A1A)
- Labels: Söhne Medium capslock, tracking extremo, cor secundária

**Seção dark (cirúrgica, < 20% do site):**
- Display: Söhne ExtraBold, branco sobre preto
- Corpo: Söhne Book 300, branco 70% opacidade
- O peso visual aumenta. A fonte não muda.

## PARTE IV — SISTEMA DE COR

### 4.1 Filosofia de Cor

A cor primária da Elysian é **ausência** — o off-white que deixa o conteúdo respirar.

Isso não é minimalismo por tendência. É uma decisão estratégica:
quando o mercado grita com cores, a Elysian faz silêncio.
O silêncio, no contexto certo, é o som mais alto da sala.

### 4.2 Paleta Fundacional

**Base Luminosa — 80% da presença visual**

```
Branco Elysian:     #FFFFFF   — superfícies primárias, hero claro
Off-white:          #F8F7F3   — superfícies secundárias, papel
Cinza Névoa:        #F2F1ED   — backgrounds alternativos, cards
Cinza Pedra:        #E8E7E2   — bordas sutis, divisores
```

**Preto Editorial — Dark cirúrgico**

```
Preto Absoluto:     #000000   — hero fase dark, máximo impacto
Preto Profundo:     #0A0A0A   — seções de tensão
Preto Técnico:      #0D0D0D   — seções de problema/dor
Cinza Fumo:         #1A1A1A   — texto principal sobre fundo claro
```

**Acento — O único momento de cor**

```
Integrity Emerald:  #10B981   — acento primário global
Emerald Hover:      #059669   — estado ativo/hover
Emerald Muted:      #10B98120 — background sutil (8% opacidade)
```

**Por que o Emerald:**
Verde é a cor da vida, do crescimento, da permissão. Em UI, é a cor do "sim", do "pode seguir", do "está correto". Para uma empresa cujo produto é elevar humanos — dar permissão para ir além — o verde é honesto. Não é escolhido por tendência.

### 4.3 Paleta das Verticais

Cada vertical tem um acento próprio que coexiste com o Emerald global:

| Vertical | Cor | Hex | Semântica |
|---|---|---|---|
| Elysian Lex | Emerald | #10B981 | Integridade, precisão |
| CRM Aurora / Silent Operator | Índigo | #4F46E5 | Confiança, sistema |
| Mad Lab Aurora | Âmbar | #D97706 | Criação, energia |

**Regra:** As cores das verticais nunca aparecem juntas na mesma tela da marca mãe. A marca mãe usa apenas o Emerald como acento. As cores de produto aparecem somente dentro do contexto daquele produto.

### 4.4 Regras de Uso de Cor

**Regra 1 — O dark é conquistado narrativamente.**
Preto só aparece depois que o visitante já respirou, confiou, e está pronto para sentir o peso da dor. Nunca como primeira impressão (exceto se o hero for dark — e mesmo assim, a seção seguinte volta ao claro).

**Regra 2 — O acento é singular.**
Uma página tem um momento de Emerald. Não cinco. Quando o acento está em todo lugar, ele não é acento — é cor de fundo.

**Regra 3 — O off-white não é branco com desculpa.**
#F8F7F3 tem personalidade. Tem temperatura. Não é "quase branco". É papel premium, é mármore leve, é a superfície onde o trabalho acontece.

**Regra 4 — Nunca gradiente de cor.**
Gradientes são proibidos na paleta Elysian. Exceção única: gradiente de opacidade do mesmo tom para criar transição entre seções (ex: off-white → transparente → preto). Nunca gradiente entre duas cores diferentes.

## PARTE V — LOGOTIPO

### 5.1 Conceito

O logotipo Elysian é o nome em tipografia com intenção — não um ícone arbitrário.

**Abordagem:** Wordmark em Söhne Halbfett (SemiBold), com tratamento de tracking e espaçamento proprietário.

O detalhe que carrega a mitologia sem explicá-la:
um elemento gráfico ultra-sutil na letra "E" ou como elemento separado — uma referência aos portões dos Campos Elísios, geométrica, contemporânea, que só quem busca vai encontrar.

**Por que wordmark:**
- O nome "Elysian" tem força fonética e visual própria
- Um ícone abstrato competiria com o nome em vez de servi-lo
- Em digital, o wordmark é mais versátil — funciona em qualquer tamanho

### 5.2 Variações

**Versão Primária:** `ELYSIAN` em capslock, Söhne SemiBold, tracking +0.15em
**Versão Secundária:** `Elysian` em sentence case, Söhne SemiBold, tracking -0.02em
**Versão Ícone:** Sigla `E` estilizada — para favicon, app icon, contextos mínimos
**Versão Tagline:** `Elysian` + `ai.br` em Söhne Book, para domínio

### 5.3 Espaço de Proteção

O logotipo sempre tem espaço de proteção equivalente à altura da letra "E" em todos os lados.

**O que nunca entra no espaço de proteção:**
- Outros elementos tipográficos
- Bordas ou molduras
- Elementos decorativos
- Cores de fundo que comprometam o contraste (mínimo 4.5:1)

### 5.4 Fundos Aprovados

| Fundo | Versão do Logo |
|---|---|
| #FFFFFF / #F8F7F3 | Logo preto |
| #000000 / #0A0A0A | Logo branco |
| Fotografia clara | Logo preto |
| Fotografia escura | Logo branco |
| #10B981 (Emerald) | Logo branco apenas — nunca preto |

## PARTE VI — SISTEMA DE IMAGEM

### 6.1 Filosofia de Imagem

As imagens Elysian não ilustram — **habitam**.

A diferença: uma imagem que ilustra explica o que o texto já disse.
Uma imagem que habita cria um mundo que o texto sozinho não alcança.

### 6.2 Direção Visual — Lado Luminoso

**O que entra:**
- Pessoas em estado de concentração e fluxo — não sorrisos posados
- Mãos e objetos com textura — papel, vidro, metal, pele
- Arquitetura com luz natural — proporção, espaço, silêncio
- Natureza com geometria — onde o orgânico e o construído se encontram

**O que nunca entra:**
- Stock photos genéricas de "equipe diversa sorrindo"
- Laptops abertos como símbolo de trabalho
- Apertos de mão
- Nuvens como metáfora de "cloud"
- Robôs, circuits, cérebros digitais como representação de IA

**Tratamento:**
- Paleta: tons frios com leveza, não processamento excessivo
- Contraste: natural, não aumentado artificialmente
- Saturação: reduzida 10–15% do original
- Proporção: sempre 16:9, 3:2 ou quadrado — nunca crops arbitrários

### 6.3 Direção Visual — Lado Dark (Seções de Tensão)

Quando a página entra no dark para mostrar a dor do cliente, a imagem muda de natureza:

**O que entra:**
- Ambientes com luz única e dramática — uma janela, uma lâmpada, um monitor
- Sombras que escondem mais do que revelam
- Texturas de superfície escura — couro, tecido, concreto
- Ausência: às vezes não há imagem — só tipografia e preto

**O que nunca entra:**
- Imagens de terror ou angústia literal
- Metáforas óbvias de "problema" (nó na corda, labirinto)
- Negatividade gratuita — a tensão existe para ser resolvida

### 6.4 Elementos Decorativos

A Elysian usa um sistema de elementos geométricos derivados da referência mitológica:

**Portões:** Linhas verticais paralelas com proporção áurea — referência ultra-sutil aos portões dos Campos Elísios. Aparecem como bordas, como separadores, como frames.

**Grid de Proporção:** Sistema de grid baseado na razão áurea (1:1.618). Não visível, mas presente em toda composição.

**Coordenadas:** Em seções técnicas e de produto, coordenadas cartesianas mínimas podem aparecer — referência à precisão de sistema, não à decoração.

**Opacidade dos elementos:**
- Seções luminosas: 15–25% de opacidade
- Seções de transição: 40–50%
- Seções dark: 60–70%

## PARTE VII — SISTEMA DE LAYOUT E ESPAÇAMENTO

### 7.1 O Princípio do Ar

O espaço negativo na Elysian não é espaço vazio.
É onde o visitante respira, processa, e confia.

**Regra operacional:**
Antes de adicionar qualquer elemento a uma composição, pergunte:
*"O que eu posso remover e ainda ter a mesma comunicação?"*
Se a resposta é "nada", o elemento fica.
Se a resposta é "algo", remove.

### 7.2 Grid Base

```
Container máximo:    1280px
Colunas:            12
Gutters:             24px (mobile: 16px)
Margins laterais:    80px (desktop) / 24px (mobile)
Baseline grid:       8px
```

### 7.3 Escala de Espaçamento

```
4px   — micro (entre label e ícone)
8px   — pequeno (padding interno de tag)
16px  — base (espaço entre elementos relacionados)
24px  — médio (padding de card)
40px  — grande (separação entre seções internas)
64px  — section (espaço entre blocos de conteúdo)
96px  — hero (margens do hero)
128px — máximo (espaço entre seções de alto impacto)
```

### 7.4 Regras de Composição

**Assimetria intencional:**
Layouts nunca são perfeitamente centrados em tudo. Um elemento âncora pode estar deslocado para criar tensão visual. Mas a assimetria tem razão — não é acidente.

**Peso tipográfico como âncora:**
Em seções luminosas, o elemento de maior peso é sempre tipográfico. Nunca uma imagem domina sobre o texto na hierarquia de leitura.

**Margens generosas:**
Nenhum texto toca a borda do container. Respira sempre.

## PARTE VIII — DARK EDITORIAL ELYSIAN

### 8.1 O Que É (e o Que Não É)

Dark Editorial na Elysian não é um tema escuro.
Não é um modo noturno.
Não é estética de startup tech.

É uma postura narrativa que aparece quando a história precisa de peso.
Inspirado na mesma lógica do Black Sabbath: pegar o Jazz e o Blues — estruturas que já existiam — e levá-los ao limite até criar algo que não tinha categoria.

Da mesma forma: pegar o editorial de alto padrão — Vogue, Harper's Bazaar — e levá-lo ao limite até criar algo que não é mais revista, não é mais site, é uma experiência que o visitante não consegue explicar.

### 8.2 Quando o Dark Entra

O dark é **conquistado narrativamente**. Nunca gratuito.

```
Seção de Impacto (Hero)  → pode começar dark ou claro
Seção de Descompressão   → SEMPRE claro (visitante respira)
Seção de Valor           → claro com transição
Seção do Problema        → AQUI o dark pode entrar
    → É aqui que mostramos a dor que o cliente nem sabe que tem
    → O preto abafa, sufoca — é exatamente isso que queremos
    → O visitante sente antes de entender
Seção de Solução         → retorno gradual ao claro
Seção de Prova           → claro
CTA Final                → pode ter acento forte / Emerald
```

### 8.3 O Teste do Dark Editorial

Antes de aplicar dark a qualquer seção, responda:

1. A narrativa **precisa** de peso aqui, ou eu só quero que pareça premium?
2. O visitante já respirou e confiou o suficiente para receber esse peso?
3. Se eu remover o fundo preto, a seção ainda tem impacto?
   - Se sim: o dark é decoração. Remove.
   - Se não: o dark é a narrativa. Mantém.

### 8.4 Regras Técnicas do Dark

- Preto Absoluto (#000000) apenas para hero e momentos de impacto máximo
- Seções dark subsequentes usam tons diferentes (#0A0A0A, #0D0D0D) para criar hierarquia
- Nunca dois pretos idênticos adjacentes — um sempre tem diferenciação de tom ou textura
- O retorno ao claro é sempre gradual (gradiente de opacidade ou seção de transição)
- Tipografia no dark: nunca branco puro (#FFFFFF) em peso leve — use 90% (#F2F2F2) para evitar vibração

## PARTE X — CHECKLIST DE VALIDAÇÃO

Antes de aprovar qualquer ativo visual Elysian:

```
IDENTIDADE
[ ] A fonte é Söhne ou GT America (não fallback em display)?
[ ] O tracking em display é negativo?
[ ] O peso segue a escala definida?

COR
[ ] O fundo primário é off-white ou branco (não cinza genérico)?
[ ] O acento Emerald aparece no máximo uma vez por seção?
[ ] Não há gradiente entre duas cores diferentes?
[ ] O dark foi conquistado narrativamente (não aplicado por estética)?

ESPAÇO
[ ] Existe ar generoso suficiente para o conteúdo respirar?
[ ] Nenhum elemento toca a borda do container?
[ ] A hierarquia de leitura é clara sem explicação?

IMAGEM
[ ] A imagem habita — ou apenas ilustra?
[ ] Não há stock photos genéricas?
[ ] O tratamento de cor segue a paleta (saturação reduzida)?

DARK EDITORIAL
[ ] O dark aparece após ao menos uma seção clara de descompressão?
[ ] Os tons de preto entre seções são diferenciados?
[ ] O retorno ao claro é gradual?
[ ] Passou no teste: "se remover o preto, o impacto some?"

MITOLOGIA
[ ] A referência mitológica está presente como subtexto (não explicada)?
[ ] Os Campos Elísios são sentidos — não nomeados?
```
