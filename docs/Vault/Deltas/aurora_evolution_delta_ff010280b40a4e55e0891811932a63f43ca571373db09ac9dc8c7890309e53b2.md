## Novos Componentes Tecnicos
- **Z-Axis Scroll Container (R3F + GSAP)**: Um container genérico em React Three Fiber / GSAP que mapeia o scroll do usuário (vertical/horizontal tradicional) em movimento linear de profundidade (eixo Z) em camadas de conteúdo, criando o efeito de túnel/mergulho.
- **Hardware-Accelerated Layer Portal**: Componentes React encapsulados que entram e saem de foco usando `clip-path` e transição de opacidade/escala controlados pela coordenada Z do viewport, evitando Layout Shift.

## Feature Requests Fundamentais
