# Pattern: SMAS Cognition (Sovereign Multi-Agent Synthesis)

## Overview
A cognitive interaction pattern that segregates agent responsibilities into a "Triad" of Source, Judge, and Escriba. While primarily a logic pattern, it dictates the "Hierarchical Truth" display in the UI—ensuring the user can distinguish between raw data and strategic narratives.

## Visual Prompt Instructions
1. **Source of Truth (Level 0)**: Display raw, unadulterated data (e.g., technical specs) in a distinct, muted "Deep Surface" area.
2. **The Verdict (Level 1)**: The "Judge's" strategic synthesis must be the primary visual focus, using high-contrast typography and specific diagnostic colors (e.g., Warning Yellow for "Anomalies").
3. **The Narrative (Level 2)**: The final "Copy" or "Interface Text" sits in a clean, legible area, clearly citing the Level 1 verdict as its source.
4. **Agent Attribution**: Use micro-labels or status indicators (e.g., `JUDGE // ACTIVE`) to show which cognitive layer is currently dominating the viewport.
5. **Flow Visualization**: If possible, include a subtle connecting line or motion path that traces the "Truth" from Source -> Judge -> User.

## Stitch-Specific Metadata
- **Keywords**: Cognitive Hierarchy, Multi-Agent UI, Verification Layers, Truth Synthesis, Strategic Focus.
- **Banned**: Single-layered narration, unverified claims, opaque data sources.
