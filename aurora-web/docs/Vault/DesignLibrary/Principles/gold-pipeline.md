# Principle: Aurora Gold Pipeline
ID: GOLD-PIPELINE
Source: Claude Library

## 1. Overview
The **Aurora Gold Pipeline** is a disciplined high-precision framework for delivering S-Tier digital experiences. It enforces a strict separation between design generation and cinematography.

---

## 2. Phases

### Phase 1: Generation (Stitch MCP)
- Produce high-fidelity static HTML/CSS.
- Focus on typography, layout, and raw visual assets.
- **Output**: Verified static design.

### Phase 2: Cinematography (Antigravity)
- Add motion, physics, and interactions.
- Apply pattern-based reveals and transitions.
- **Standard**: Zero modification of Phase 1 output.

### Phase 3: Deployment (Production)
- Convert to **Next.js 15 (App Router)**.
- Implement **Tailwind CSS v4**.
- Final optimization (Lighthouse 90+, < 0.1 CLS).

---
