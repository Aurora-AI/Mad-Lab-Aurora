# EFFECT: Emotional Physics (Motion DNA)

## Overview
A set of curated motion presets that define the "Temperament" of the interface. Instead of generic easings, this effect uses physical parameters (Damping, Speed, Noise) to infuse the UI with character—ranging from "Light/Airy" to "Heavy/Monolithic".

## Motion Presets
When prompting for motion, use these DNA profiles:

1. **HEAVY (The Monolith)**:
   - *Vibe*: Moving stones, metal, or massive architecture.
   - *Damping*: `0.85`, *Speed*: `0.02`.
   - *Usage*: High-authority section entries, transition of large structural blocks.

2. **BALANCED (The Standard)**:
   - *Vibe*: Responsive, confident, with mass.
   - *Damping*: `0.92`, *Speed*: `0.05`.
   - *Usage*: Buttons, cards, standard UI navigation.

3. **AIRY (The Ghost)**:
   - *Vibe*: Smoke, bacteria, or light clouds.
   - *Damping*: `0.96`, *Speed*: `0.03`, *Noise*: `0.15`.
   - *Usage*: Background textures, micro-hover interactions, atmospheric backgrounds.

4. **PRECISION (The Robot Arm)**:
   - *Vibe*: Clinical precision, no overshoot.
   - *Damping*: `0.60`, *Speed*: `0.20`.
   - *Usage*: Dashboard data updates, grid alignments.

## Visual Prompt Instructions
- Avoid "Speed: Fast" or "Easing: Ease-in".
- Use descriptive physics: "Apply **Heavy Motion DNA** with high damping for a monolithic feel."

## Stitch-Specific Metadata
- **Vibe Keywords**: Weighty, Physical, Temperamental, Eased, Damped.
- **Banned**: Linear animations, Standard CSS easings, Instant state changes.
