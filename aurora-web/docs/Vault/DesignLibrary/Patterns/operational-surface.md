# Pattern: Operational Surface

## Overview
A high-density interaction layout designed for "Silent Operators." It combines forensic data grids with organic-deterministic 3D archetypes (ARC), creating a "Control Room" atmosphere. It avoids the friendly, soft "SaaS dashboard" look in favor of a clinical, high-gravity interface.

## Visual Prompt Instructions
1. **Grid Density**: Use a 12 or 24 column grid with zero or minimal gutters.
2. **Surface Tiers**: Distinguish sections through subtle background tonal shifts (Zinc-950, Zinc-900, Zinc-800) rather than 1px solid borders.
3. **ARC Integration**: Dedicate a central, zero-margin zone for a 3D organic structure (e.g., Chronos Nautilus). The UI should "orbit" this asset.
4. **Data Mono**: All metrics, labels, and timestamps must use a Monospace font (e.g., Geist Mono) to emphasize the forensic/technical nature.
5. **Interactive Diagnostic**: Hover states should trigger "Deep Diagnostic" data reveals (e.g., showing raw DNA parameters or precise metrics in a glassmorphism overlay).
6. **No-Line Sectioning**: Ensure section separation is achieve through "Surface Tiering" (background color change) only.

## Stitch-Specific Metadata
- **Keywords**: High Density, Forensic Grid, Tonal Surface, Mono Labels, Control Room, Operator Workspace.
- **Banned**: 1px borders, white backgrounds, rounded cards (use sharp, angular container zones).
