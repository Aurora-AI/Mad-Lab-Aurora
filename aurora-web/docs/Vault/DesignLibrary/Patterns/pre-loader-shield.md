# PATTERN: Pre-loader Shield (Brand Authority)

## Overview
A high-authority loading state that transitions the user from the "Unknown" to the "System". It uses high-density silhouettes and numeric progress indicators to signal that the interface is "Computing" or "Analyzing".

## Visual Prompt Instructions
When implementing this pattern, follow these semantic rules:

1. **Central Asset (The Shield)**:
   - A high-contrast, strictly geometric silhouette or symbol centered in the viewport.
   - Recommended: "The Puzzle Woman" silhouette or a complex brand monogram.

2. **Epistemic Load Indicator**:
   - Progressive numeric counter using Monospace fonts (e.g., "0% ... 100%").
   - Label: "ESTABLISHING EPISTEMIC LINK" or "LOADING AUTHORITY PROTOCOLS".

3. **Transition (The Reveal)**:
   - Upon completion, the white screen must "shatter" or "slide" to reveal the dark interface below.
   - Use high-speed **Elastic Motion DNA** for the final exit.

4. **Atmosphere**:
   - Background: Pure White (#FFFFFF) to signal clinical clarity.
   - Foreground: Stark Black (#000000) for the asset and text.

## Stitch-Specific Metadata
- **Vibe Keywords**: Authoritative, Clinical, Deterministic, Loading, High-Contrast.
- **Banned**: Loading spinners, Progress bars (graphic), Soft colors, "Loading..." text.
