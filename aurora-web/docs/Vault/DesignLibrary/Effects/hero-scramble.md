# EFFECT: Hero Scramble (Forensic Reveal)

## Overview
A signature text animation effect that transitions from "Algorithmic Noise" to "Deterministic Truth". It uses random character scrambling that progressively freezes into high-authority headlines.

## Visual Prompt Instructions
When implementing this effect, follow these semantic rules:

1. **Initial State (Uncertainty)**:
   - Occupy the headline area with rapidly changing, random alphanumeric characters or symbols.
   - Contrast: High contrast against a dark background is mandatory.

2. **Transition (The Auditor's Focus)**:
   - Characters must "freeze" into the target text from left to right or in a "flicker-resolve" pattern.
   - The resolved text should be massivly scaled (Crimson Pro) with tight tracking.

3. **Supporting Environment**:
   - The effect should be layered over a structural grid (1px lines) or a noise texture.
   - Use a "Diagnostic" color palette: Pure White (#FFFFFF) text on Off-Black background.

4. **Timing**:
   - Total reveal duration: ~3000ms to 5000ms.
   - The "freeze" should feel mechanical and deterministic, not fluid or organic.

## Stitch-Specific Metadata
- **Vibe Keywords**: Forensic, Auditor, Algorithmic, Deterministic, High-Contrast.
- **Banned**: Smooth fades, Gradient transitions, Organic motion, Playful fonts.
