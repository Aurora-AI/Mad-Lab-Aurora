## Pending Ingestion

### KI-WEB-001 — Hero Seção = Maior ROI do Site
**Origem:** CEO-Web SKILL.md + Halo Effect 50ms  
**Aprendizado:** A primeira impressão em 50ms define o filtro pelo qual todo o resto do site é julgado. Impressão positiva = filtro de confiança. Impressão negativa = ceticismo permanente que nenhum conteúdo subsequente remove. O hero não é estética — é infraestrutura de conversão.  
**Status:** Candidato para aprovação

### KI-WEB-002 — Prova Social Antes do CTA, Sempre
**Origem:** CEO-Web calibração por produto  
**Aprendizado:** A pergunta que a prova social responde é sempre a mesma: "isso funcionou para pessoas como eu?". Posicionar a prova social depois do CTA principal inverte a lógica de confiança — o visitante precisa confiar antes de agir.  
**Status:** Candidato para aprovação

### KI-WEB-003 — Advogado Solo: "Startup" é Kryptonita
**Origem:** Calibração ICP Elysian Lex  
**Aprendizado:** O ICP do Elysian Lex é conservador, com alta sensibilidade a sigilo e credibilidade. Qualquer elemento visual ou textual que pareça "startup de tecnologia" ativa o filtro de desconfiança. Premium por sobriedade converte. Overdesign sabota.  
**Status:** Candidato para aprovação
