# Candidatos a Indicadores de Conhecimento (KIs) — Mad Lab

Este diretório contém os rascunhos e KIs candidatos gerados pelo loop de Reflexão local do Mad Lab Aurora.

### Fluxo de Promoção
1. O erro de compilação, performance ou design visual é corrigido.
2. O `agent-reflexion-code` gera o arquivo `.json` ou `.md` do KI candidato neste diretório.
3. O `Bibliotecário` realiza a sanitização e validação.
4. Passa pelo Gate de Validação Humana / QA.
5. Se aprovado, o arquivo é promovido para a pasta `Vault/KIs/approved/`.
