# PATTERN: Evidence Canvas (Structured Analysis)

## Overview
A high-density structural layout used for displaying verifiable data, logs, or analysis results. It replaces "Decorative" grids with "Functional" ones, infusing the interface with the authority of an audit tool.

## Visual Prompt Instructions
When implementing this pattern, follow these semantic rules:

1. **The Grid (The Logic)**:
   - Faint but visible 1px solid grid lines (Off-White or Gray-900).
   - The grid defines the placement of all elements—no "free floating" text.

2. **Interactive Markers**:
   - Use subtle "Glow" effects (Audit Green or Accent color) only upon validation or data lookup.
   - Contrast between the sharp grid and soft glow highlights the "Discovery" of information.

3. **Data Density**:
   - Use Monospace fonts for numbers, identifiers, and timestamps.
   - Labels should be placed at the intersections of grid lines.

4. **Atmosphere**:
   - Monochromatic primary palette.
   - Restricted vertical spacing—prefer horizontal density for a "Cockpit" feel.

## Stitch-Specific Metadata
- **Vibe Keywords**: Systematic, Structured, Forensic, Diagnostic, High-Density.
- **Banned**: Cards with rounded corners, Fluid gradients, Spaced-out bento grids.
