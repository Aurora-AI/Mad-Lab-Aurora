# Indicadores de Conhecimento (KIs) Aprovados — Mad Lab

Este diretório contém as vacinas cognitivas aprovadas e consolidadas para os subprojetos do Mad Lab Aurora.

### Uso
* Esses KIs são lidos pelo `reflexion digest` no preflight de novas OSs para evitar a reintrodução de bugs históricos relacionados a GSAP, Three.js, React 19 e builds do Astro.
* KIs transversais que se aplicam a todo o ecossistema Aurora podem ser propostos para promoção ao Vault global da fábrica (`Ozzmosis`).
